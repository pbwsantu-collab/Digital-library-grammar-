## 📖 Overview

This comprehensive HTML-based digital library contains **over 320+ grammar exercises** specifically curated for **Class IX** students. It covers essential English grammar topics with a focus on transformation of sentences, parts of speech, and voice change.

---

## 🎯 Topics Covered

### 1. **Degree of Comparison** (50+ exercises)
- Positive → Comparative → Superlative transformations
- All three degrees covered extensively
- Includes special patterns (one of the, very few, no other)

### 2. **Parts of Speech** (36+ exercises)
- Conversion between:
  - Adjective ↔ Adverb
  - Noun ↔ Adjective
  - Abstract Noun ↔ Adjective
  - Adjective ↔ Abstract Noun
- Practical sentence-based transformations

### 3. **Cannot but / Cannot help** (30+ exercises)
- Transformations using:
  - `cannot but` + base verb
  - `cannot help` + gerund (-ing form)
- Practice with modal verbs (must, should, etc.)

### 4. **Voice Change - Active to Passive** (320 exercises)
- **Tenses covered:**
  - Simple Present, Past, Future
  - Present/Past/Future Continuous
  - Present/Past/Future Perfect
  - Perfect Continuous (selected)
  
- **Special structures:**
  - Modal verbs (can, could, may, might, should, must)
  - Modal + Perfect (must have, may have, etc.)
  - Imperatives (commands, requests)
  - Interrogatives (Yes/No and Wh-questions)
  - Two Objects (give, teach, send, tell, offer)
  - Passive with "get"
  - Passive of Infinitives (to be + V3)
  - Passive of Gerunds (being + V3)
  - Passive with Prepositions (look after, talk about, laugh at)
  - Causatives (let, make, help)
  - Verbs of Perception (see, hear, watch)
  - "Need/require/want" + gerund
  - "Have/Get something done" (causative passive)
  - Reporting Verbs (It is said/known/believed...)
  - Negative sentences
  - Sentences without Agent
  - Common Error Fixing

## 💡 Pro Tips for Students

1. **Degree of Comparison**: Remember the three-step formula:
   - Positive: `as + adjective + as`
   - Comparative: `adjective + -er + than`
   - Superlative: `the + adjective + -est`

2. **Parts of Speech**: Look for suffixes:
   - `-ly` = adverb (usually)
   - `-ness`, `-tion`, `-ment` = noun (often)
   - `-ous`, `-ful`, `-less` = adjective (often)

3. **Cannot but/help**:
   - `cannot but` + base verb (respect, obey)
   - `cannot help` + gerund (-ing form)

4. **Voice Change**:
   - Identify the tense first
   - Use correct form of `to be`
   - Past participle (V3) is always used
   - Subject ↔ Object interchange

## 📌 Quick Reference

**Common Transformation Rules:**

| From | To | Rule |
|------|-----|------|
| Positive | Comparative | `as + adj + as` → `adj + -er + than` |
| Comparative | Superlative | `adj + -er + than any other` → `the + adj + -est` |
| Adjective | Adverb | Add `-ly` (careful → carefully) |
| Verb | Noun | Use suffix `-tion`, `-ment`, `-ance` |
| Must | Cannot but | `must + V1` → `cannot but + V1` |
| Must | Cannot help | `must + V1` → `cannot help + V1ing` |
| Active | Passive | Subject ↔ Object, use `to be + V3` |
