## 📌 Overview

**Macbeth Interactive Study Guide** is a comprehensive, self-contained HTML learning resource designed for students, teachers, and literature enthusiasts. It transforms Shakespeare's classic tragedy "Macbeth" into an interactive educational experience with:

- 📖 Complete text with 100% word-by-word Bengali translations
- 📊 Critical literary analysis
- ❓ 200 multiple-choice questions
- 🧙 An interactive "Three Witches" game
- 🎨 Visual scene gallery

> **🎯 Perfect for:** Bangladeshi students, ESL learners, literature students, teachers preparing lessons, and self-study enthusiasts.

---

## ✨ Features

### 🔮 1. Full Text with Word Meanings
- **Complete play text** (8 pages)
- **100% word coverage** - Every English word has Bengali meaning
- **Click-to-reveal** translations
- **Interactive word meanings** - Click any word to see Bengali translation
- **Visual highlighting** of translated words

### 📊 2. Critical Analysis
- **Themes & Motifs** - Ambition, Guilt, Appearance vs Reality, Supernatural, Manhood
- **Character Analysis** - Macbeth, Lady Macbeth, Witches, Banquo, Macduff
- **Symbols** - Blood, Dagger, Sleep, Birnam Wood, Crown, Cauldron
- **Tragic Structure** - Aristotelian analysis (Hamartia, Peripeteia, Anagnorisis, Catharsis)

### ❓ 3. 200 Multiple Choice Questions
Organized into 8 comprehensive sets:
- **Set 1-2:** General Knowledge (50 questions)
- **Set 3:** Quotes & Meanings (25 questions)
- **Set 4:** Symbols & Themes (25 questions)
- **Set 5:** Plot & Sequence (25 questions)
- **Set 6:** Advanced Analysis (25 questions)
- **Set 7:** Context & Background (25 questions)
- **Set 8:** Dramatic Techniques (25 questions)

**Interactive Features:**
- Click any answer to check correctness
- Wrong answers reveal the correct option
- 100% self-grading

### 🧙 4. Three Witches Interactive Game
- **3 witch characters** to click on
- Each reveals a quiz question
- **✨ Correct answer:** Fairy appears with sparkle animation
- **👻 Wrong answer:** Ghost appears with fade animation
- Fun, engaging way to test knowledge

### 🎨 5. Scene Gallery
- **5 illustrated scenes** with visual descriptions:
  1. Witches on the Heath (🌩️)
  2. Floating Dagger (🗡️)
  3. Banquo's Ghost (👻)
  4. Birnam Wood Moving (🌳)
  5. Final Battle (⚔️)
- Each scene includes atmospheric descriptions
- Emoji-based visual representation

### 🎯 6. Interactive Menu
- **5 color-coded sections**
- **One-click navigation**
- **Smooth transitions**
- **Mobile-responsive design**

## 🚀 How to Use

### Quick Start
1. **Download** the `macbeth.html` file
2. **Double-click** to open in your browser
3. **Navigate** using the colorful menu
4. **Click** any word to see Bengali meaning
5. **Answer** MCQs by clicking options
6. **Play** the Three Witches game

### Navigation Guide

| Menu Item | Color | What You'll Find |
|-----------|-------|------------------|
| 📖 Full Text | 🟣 Purple | Complete play with word meanings |
| 📊 Analysis | 🩷 Pink | Thematic and character breakdowns |
| ❓ MCQs | 🟡 Gold | 200 interactive questions |
| 🧙 Witches | 🟢 Green | Interactive quiz game |
| 🎨 Gallery | 🔵 Blue | Scene illustrations |

### Learning Path Recommendation

```
1. Start with "Full Text"
   → Read the play
   → Click words for Bengali meanings

2. Move to "Critical Analysis"
   → Understand themes
   → Study character development

3. Practice with "MCQs"
   → Test your knowledge
   → Review answers

4. Play "Three Witches Game"
   → Fun reinforcement
   → Quick recall practice

5. Explore "Scene Gallery"
   → Visual understanding
   → Scene visualization
```
